# S-050: Recovery/intervention literature flagged for future Q7 revisit

Gary supplied two arXiv papers to keep on file in case node "deactivation" is
revisited later, despite D-031's rejection of Track 4 (SIR-style recovery/healing):

- **Coker & Gunderson (2015)**, arXiv:1505.08030 — proves a sharp threshold for a
  specific non-monotone 2-neighbour bootstrap-percolation rule where infected sites
  with zero infected neighbours recover. Directly on-point as an existence proof that
  a narrow recovery rule can still admit a sharp threshold.
- **Ballen & Guha (2015)**, arXiv:1512.00834 — non-uniform-threshold bootstrap
  percolation sharp dichotomy, plus post-hoc behavioral interventions (edge deletion /
  threshold increase) that halt spread after a residual state is reached. Not a
  recovery model, but adjacent: non-uniform-threshold ER technique, and an alternate
  non-monotone-feeling mechanism (halting future failures) that doesn't touch
  monotonicity of the failed set the way literal recovery does.

Added both as `okf/references/coker-gunderson-2015.md` and
`okf/references/ballen-guha-2015.md` (index updated), and appended a dated note to the
Q7 line in `okf/open-questions.md` pointing to them. **No decision entry** — this does
not reverse or alter D-031 (`okf/decisions/d-031-discard-tracks-4-5.md`); Track 4 stays
rejected. This is reading material on file only, for if/when Gary chooses to reopen the
question himself.
