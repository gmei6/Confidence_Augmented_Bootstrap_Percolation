\section{The Setup}
\vspace{-0.3em}
The existing baseline (Janson) gives a bank exactly \textbf{one way to fail}: enough of its neighbors have already activated.

\vspace{0.3em}
Janson et al.\ solved that case on the Erd\H{o}s--R\'enyi graph, as bootstrap percolation with threshold $r$. I add a \textbf{second way for nodes to activate}.

\vspace{-1.5em}
\section{The Model}
\vspace{-0.3em}
A node is activated if either condition is met:
\vspace{0.2em}
% Converted equations to inline math ($...$) to save ~2 inches of vertical space!
\begin{enumerate}[leftmargin=*, nosep, itemsep=0.3em]
\item \textbf{Percolation:} At least $r$ of its neighbors have failed ($|\{j \sim i : j \in A_t\}| \geq r$).
\item \textbf{Fear:} A Bernoulli variable with probability $f_ig_t$ that a node activates ($U_i < f_i\, g_t$).
\end{enumerate}

\vspace{-1.5em}
\section{The Comparisons}
\vspace{-0.3em}
We hold network size $n$ and average degree constant across all tests to isolate three items:
\vspace{0.2em}
\begin{itemize}[leftmargin=*, nosep, itemsep=0.3em]
  \item \textbf{Heterogeneity:} \\
  Homogeneous degree distribution vs.\ heavy-tailed hubs.
  \item \textbf{Geometry:} \\
  Pure random connections vs.\ local spatial clustering.
  \item \textbf{Fear:} \\
  Baseline bootstrap percolation vs.\ confidence augmentation.
\end{itemize}

The same fear that cuts ER's tipping point by 65\% cuts the heavy-tailed
networks' by only $\sim$35\% at $\bar\mu = 0.4$ --- hubs blunt fear's
effect, and geometry doesn't change that. Fear also sharpens the transition
faster as the network grows: $\nu(\mu = 0) = 5.61 \pm 0.18 \to
\nu(\mu = 0.3) = 4.82 \pm 0.15$, verified.
